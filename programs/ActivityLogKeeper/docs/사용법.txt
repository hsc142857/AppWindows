ActivityLogKeeper 사용법
========================

로그인된 Chrome에서 웹 프로그램의 "활동 로그(이력)" 화면을 주기적으로 읽어
표의 행을 이 PC(SQLite)에 보관하고, 설정하면 서버(Web API)로도 올립니다.
서버에 문제가 생기거나 상대 서비스의 기록이 바뀌어도, 언제 무엇이 보였는지 PC에 남습니다.

1. 설치
   - 이 폴더를 원하는 위치에 둡니다 (예: C:\Tools\ActivityLogKeeper).
   - ActivityLogKeeper.exe를 실행하면 화면 오른쪽 아래 알림 영역(트레이)에 아이콘이 생깁니다.
     아이콘을 클릭하거나 메뉴의 [관리 창 열기]로 관리 창을 엽니다.
   - 관리 창 [설정] 탭 → [Chrome 호스트 등록]을 누릅니다.
     (같은 폴더의 activitylogkeeper-cli.exe를 등록합니다. 폴더를 옮기면 다시 누르세요.)
   - Windows 시작 시 자동 실행하려면 ActivityLogKeeper.exe 바로 가기를
     시작 프로그램 폴더(Win+R → shell:startup)에 넣습니다.

2. Chrome 확장 설치 (처음 한 번)
   - Chrome 주소창에 chrome://extensions 입력
   - 오른쪽 위 [개발자 모드] 켜기
   - [압축해제된 확장 프로그램을 로드합니다] → 이 폴더의 extension 폴더 선택
   - 확장 ID가 bokkckkphfafbndhkgncoledplffljih 인지 확인

3. 수집 대상 추가 (관리 창 [대상] 탭)
   - 활동 로그가 보이는 페이지 URL과 이름을 넣고 [추가]를 누릅니다
     (한 페이지에 최대한 많은 행이 보이는 주소가 좋습니다).
   - 표를 잘못 고르면 [수정]에서 CSS 선택자를 지정합니다
     (Chrome 개발자 도구에서 표를 우클릭 → Copy selector). 비우면 행이 가장 많은 표를 읽습니다.
   - Chrome에서 해당 사이트에 로그인해 둡니다.
   - Chrome 툴바의 확장 아이콘 → [지금 수집]으로 바로 확인할 수 있습니다.
   - 로그인이 풀리거나 표를 찾지 못하면 트레이 알림이 뜨고 [개요] 탭에 표시됩니다.

4. 확인 / 내보내기
   - [로그] 탭: 대상·기간을 골라 최근 행을 보고, [CSV 내보내기]로 같은 조건의 전체 행을 저장합니다.
     CSV는 Excel에서 바로 열립니다 (처음 확인·마지막 확인 시각, 서버 전송 여부 포함).
   - [수집 기록] 탭: 언제 몇 행이 보였는지, 새 행이 몇 개였는지 봅니다.

5. 수집 주기 / Web API (관리 창 [설정] 탭)
   - 수집 주기 (초, 최소 30초, 기본 10분)와 로딩 후 대기 시간을 정합니다.
   - Web API 주소와 토큰을 넣고 [접속 테스트] → [저장]합니다.
     토큰은 한 번만 입력하면 Windows DPAPI로 암호화해 저장합니다.
   - Web API를 설정하지 않아도 PC에는 저장됩니다. 트레이 메뉴 [지금 동기화]로 바로 올릴 수 있습니다.

6. 명령 프롬프트 (선택)
   같은 일을 activitylogkeeper-cli.exe로도 할 수 있습니다:
       activitylogkeeper-cli.exe install-host
       activitylogkeeper-cli.exe target add https://app.example.com/activity 업무앱
       activitylogkeeper-cli.exe target selector 1 "#activityLog table"
       activitylogkeeper-cli.exe status          요약 (로그인 필요·표를 찾지 못한 대상 표시)
       activitylogkeeper-cli.exe captures        수집 기록
       activitylogkeeper-cli.exe entries 50      최근 로그 50행
       activitylogkeeper-cli.exe export --from 2026-10-01 --to 2026-10-31 --out 10월.csv
       activitylogkeeper-cli.exe interval 600
       activitylogkeeper-cli.exe api set https://api.example.com

알아 둘 점
   - 수집은 Chrome이 켜져 있는 동안에만 됩니다.
   - 같은 내용의 행은 한 번만 저장하고, 다시 보이면 "마지막 확인" 시각만 바뀝니다.
   - "3분 전"처럼 매번 바뀌는 시각이 들어간 표는 매번 새 행으로 저장됩니다. 가능하면 절대 시각이 보이는 화면을 쓰세요.
   - 서버 전송이 실패하면 PC에 남겨 두고 다음 수집 때 다시 보냅니다.
   - 대상을 지워도 이미 모은 로그는 지워지지 않습니다.
   - 데이터 위치: %LOCALAPPDATA%\ActivityLogKeeper (activitylog.sqlite, api.json, host.log)
   - 수집은 Chrome 확장이 하므로 트레이 앱을 종료해도 계속됩니다 (알림만 멈춤).
   - 제거: 트레이 종료 → activitylogkeeper-cli.exe uninstall-host 실행 → 폴더 삭제
